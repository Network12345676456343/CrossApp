## Лабораторна робота 4: Доменна модель, інваріанти, інкапсуляція

### Перелік інваріантів

1. **Обов'язкові текстові поля**: Ідентифікатор примірника (`id`), `ISBN` та назва книги (`title`) не можуть бути null, порожніми або складатися виключно з пробілів (`ArgumentException`).
2. **Неможливість повторної видачі**: Примірник книги неможливо видати, якщо він уже перебуває у стані видачі (`IsIssued == true`) (`InvalidOperationException`).
3. **Неможливість повернення наявної книги**: Неможливо зафіксувати повернення примірника, якщо він не був виданий (`IsIssued == false`) (`InvalidOperationException`).
4. **Валідність відкриття видачі**: Примірник книги (`copy`) та читач (`readerId`) є обов'язковими для створення запису видачі; дата видачі (`issuedAtUtc`) не може бути в майбутньому часі (`ArgumentNullException` / `ArgumentException` / `ArgumentOutOfRangeException`).
5. **Хронологія повернення**: Дата фактичного повернення книги (`returnedAtUtc`) не може передувати даті її видачі (`issuedAtUtc`) (`ArgumentOutOfRangeException`).
6. **Життєвий цикл видачі (State Machine)**: Переходи між станами (`LoanStatus.Active` -> `Returned`, `Active` -> `Cancelled`) контролюються виразом `switch`; завершену або скасовану видачу неможливо закрити чи скасувати повторно (`InvalidOperationException`).
7. **Ліміт видач читача (міжсутнісний інваріант)**: Читач не може мати більше 5 активних видач одночасно; перевірка інкапсульована в доменній політиці `LoanPolicy` (`InvalidOperationException`).
