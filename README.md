## Лабораторна робота 2: Бібліотека Core та публікація

### Структура проєкту та архітектура
Рішення розділене на два проєкти:
* `Core` (`classlib`) — інкапсулює бізнес-логіку та збір системних даних.
* `Cli` (`exe`) — консольний інтерфейс, призначений виключно для виводу даних.

Напрямок залежностей: `Cli` -> `Core` (односторонній).

Планована структура в Core:
* `Core/Dto/` — record-типи передачі даних.
* `Core/Domain/` — сутності з поведінкою та інваріантами.
* `Core/Storage/` — реалізації сховищ.

### Порівняння режимів публікації

| RID | Режим | Розмір publish | Потрібен runtime |
| :--- | :--- | :--- | :--- |
| win-x64 | self-contained | ~76.7 МБ | Ні |
| win-x64 | framework-dependent | ~0.3 МБ | Так (.NET 10) |

* **Self-contained**: пакує застосунок разом із копією .NET Runtime (CLR) та бібліотеками BCL. Дозволяє запускати програму на машині без встановленого .NET, проте займає значний обсяг.
* **Framework-dependent**: містить лише скомпільований код застосунку та сторонні бібліотеки. Вимагає попередньо встановленого середовища .NET на машині клієнта.
