\# CrossApp



Наскрізний проєкт з крос-платформного програмування.



\## Предметна область

\* \*\*Назва:\*\* Бібліотека

\* \*\*Сутності:\*\* `Book` (видання), `BookCopy` (примірник), `Reader` (читач), `Loan` (видача).

\* \*\*Призначення:\*\* Облік видач примірників книг читачам та контроль повернень.

dotnet build
