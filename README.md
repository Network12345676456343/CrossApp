# Лабораторна робота № 7. Звіти через LINQ to Objects

## Тема роботи
Створення звітів за допомогою LINQ to Objects: фільтрація, проєкція, групування, сортування, вибірка Top-N та агрегатні операції.

## Мета роботи
Ознайомитися з можливостями LINQ to Objects у мові C#. Навчитися виконувати фільтрацію, групування, сортування та проєкцію колекцій, формувати звіти й обчислювати агрегатні показники. Дослідити механізм відкладеного виконання LINQ-запитів.

## Опис виконаної роботи

У межах лабораторної роботи № 7 у проєкті `CrossApp` реалізовано сервіс звітності `ReportService`, розташований у просторі імен `CrossApp.Core.Reports`.

Сервіс відповідає за формування звітів на основі колекцій об'єктів бібліотечної предметної області. Для цього використано LINQ to Objects, який дає змогу виконувати запити безпосередньо до колекцій у пам'яті.

| Метод | Призначення | Основні оператори LINQ |

### 2. Групування даних за допомогою GroupBy

Для формування звіту про розподіл видач за читачами реалізовано метод `ByUnit`.

Використано методний синтаксис LINQ:

```csharp
public static IReadOnlyList<GroupSummary> ByUnit(IEnumerable<StockLine> source)
{
    ArgumentNullException.ThrowIfNull(source);

    return source
        .GroupBy(l => l.ReaderId, StringComparer.OrdinalIgnoreCase)
        .Select(g => new GroupSummary(
            Key: g.Key,
            Count: g.Count(),
            TotalQuantity: g.Count()))
        .OrderByDescending(s => s.Count)
        .ThenBy(s => s.Key, StringComparer.OrdinalIgnoreCase)
        .ToList();
}
```

Додатково реалізовано метод `ByUnitQuerySyntax`, який виконує аналогічне групування за допомогою декларативного синтаксису LINQ:

```csharp
public static IReadOnlyList<GroupSummary> ByUnitQuerySyntax(
    IEnumerable<StockLine> source)
{
    ArgumentNullException.ThrowIfNull(source);

    var query = from item in source
                group item by item.ReaderId into g
                let total = g.Count()
                orderby total descending, g.Key
                select new GroupSummary(g.Key, total, total);

    return query.ToList();
}
```

Основні елементи групування:

- `GroupBy` — об'єднує елементи колекції за заданим ключем.
- `g.Key` — містить значення ключа поточної групи.
- `g.Count()` — визначає кількість елементів у групі.
- `OrderByDescending` — сортує групи за спаданням кількості записів.
- `ThenBy` — забезпечує додаткове сортування за ідентифікатором читача.

Таким чином, обидва варіанти дають змогу отримати впорядковану статистику за читачами.

### 3. Дослідження відкладеного виконання LINQ

Для дослідження механізму Deferred Execution реалізовано окрему CLI-підкоманду:

```bash
dotnet run --project src/Cli -- demo-deferred
```

Відкладене виконання означає, що LINQ-запит не обчислюється безпосередньо під час оголошення. Обчислення починається лише під час фактичного отримання результатів, наприклад через `Count()`, `ToList()` або `foreach`.

Приклад:

```csharp
var query = source.Where(l => l.DueDate < DateTime.Today);
```

На цьому етапі створюється запит, але фільтрація ще не виконується.

Під час першого виклику `query.Count()` відбувається обчислення кількості відповідних елементів.

Після додавання нового запису до вихідної колекції `source` повторний виклик `query.Count()` виконує запит заново та враховує новий елемент.

Для фіксації результату використовується `ToList()`, який матеріалізує запит у нову колекцію. Подальші зміни вихідного джерела вже не впливають на отриманий знімок даних.

## Висновок

Під час виконання лабораторної роботи № 7 було досліджено та практично застосовано LINQ to Objects у середовищі .NET 10.

Реалізовано сервіс `ReportService`, який забезпечує формування звітів для бібліотечної системи. На практиці використано основні оператори LINQ для фільтрації, групування, сортування, проєкції, об'єднання колекцій та обчислення агрегатних показників.

Окремо розглянуто два варіанти запису LINQ-запитів: методний синтаксис (Method Syntax) та синтаксис запитів (Query Syntax). Також досліджено відкладене виконання запитів і різницю між повторним обчисленням послідовності та її матеріалізацією за допомогою `ToList()`.
